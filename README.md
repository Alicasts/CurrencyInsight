# Currency Comparison App

## Overview
This Android application allows users to compare exchange rates of different currency pairs, visualize historical price trends, and access real-time market data. The app features a user-friendly interface with a modern and responsive design.

![Demo](docs/DemoGif.gif)

## Features
- **Real-time Currency Pair Comparison**: View exchange rates and trends.
- **Historical Data Visualization**: Track past exchange rate fluctuations using graphs.
- **Offline Support**: Stores recent data locally to reduce API calls.
- **Smart Fetching Strategy**: Updates currency data based on a time-based refresh system.
- **Modern UI Design**: Uses XML layouts with Jetpack Compose components.

## Tech Stack
- **Architecture**: MVVM with Repository Pattern & Use Cases
- **UI**: XML + Jetpack Compose + ConstraintLayout
- **Database**: Room
- **Dependency Injection**: Hilt
- **Networking**: Retrofit + OkHttp
- **Charts**: MPAndroidChart
- **Testing**: JUnit, Espresso, MockK

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/Alicasts/CurrencyInsight
   ```
2. Open the project in Android Studio.
3. Sync Gradle and build the project.
4. Run the application on an emulator or a physical device.
